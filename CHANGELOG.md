# Changelog / История версий

All notable changes to the Cruelty Squad Russian Localization are documented here.

---

## [v2.4] — 2026-11-21

### 🔧 Fixed / Исправлено
- **«Дом» / "House" purchase bug** — полностью устранён баг бесплатной разблокировки дома: убраны все точки с запятой из мультилайн-литералов GDScript, добавлена проверка `item == "House"` в оригинальной латинице для корректной работы `savegame.save`
- **Auto-heal сохранений v2.0–v2.2** — скрипт `16_5_autoheal_and_clean_diff.py` автоматически находит и чинит сейвы, сломанные предыдущими версиями
- **Ачивка «Экстравагантный костюм»** (Extravagant Suit achievement) — исправлена проверка имени предмета, ачивка теперь срабатывает корректно в русской версии
- **Подбор «Костюма биохимзащиты»** (Biochemical Suit pickup) — исправлен триггер подбора, предмет распознаётся движком правильно

## [v2.3] — 2026-11-20

### ✨ Added / Добавлено
- **Речь и анимация Хендлера на кириллице** — восстановлена голосовая озвучка (speech voice), анимация открывания рта (mouth animation) и эффект печатной машинки (typewriter effect) при отображении кириллического текста брифингов
- **Финальный Pre-Pack Линтер** — усиленная версия линтера: проверяет кириллицу в именах нод, целостность GDScript после патча, отсутствие сдвигов индексов массивов, корректность экранирования кавычек

### 🔧 Fixed / Исправлено
- **Глобальный аудит строковых проверок имплантов** — все `if item == "..."` проверки для имплантов приведены к латинским оригиналам, предотвращая ложное срабатывание при кириллических именах

## [v2.0] — 2026-11-07

### ✨ Added / Добавлено
- **Полная русская локализация** — первый полноценный релиз: меню, брифинги, диалоги, названия уровней, имена NPC, описания имплантов
- **Достижения Steam** — 100% покрытие всех Steam-ачивок на русском языке
- **Чистый Python-пайплайн** — 19 скриптов для полного цикла: аудит → извлечение → глоссарий → перевод → валидация → сборка `.pck`
- **Pre-Pack Линтер** — автоматическая проверка целостности всех пропатченных файлов перед финальной упаковкой
- **Канонический глоссарий** — 200+ терминов с учётом лора (биопанк, корпоративный канцелярит, гностический фатализм)

### 📋 Technical / Техническое
- Pure Python binary PCK v1 parser & builder (no gdre_tools dependency for packing)
- 16-byte data alignment, MD5 file integrity verification
- Safe string extraction with 7-rule filtering (forbidden extensions, engine calls, node paths, signals, animations, Steam API, resource paths)
- 3-way merge: vanilla EN → old RU → new RU with technical invariant preservation
